## Backend and resource policy

Ripserr 0.3.0 is primary for every view.

- Cell view: 600 seconds and 4 GiB RSS; no backend substitution.
- Gene view: 1,800 seconds and 8 GiB RSS for Ripserr.
- Gene resource fallback: TDA 1.9.4 `ripsDiag` using its exact GUDHI backend,
  permitted only after the primary 8-GiB RSS stop, with 1,800 seconds and
  12 GiB RSS.

The fallback must preserve the same complete-VR, field-2, H0/H1 estimand.
Its capped connected-component class is normalized back to essential H0.
No scientific-result failure, numerical preference, or convenience switch
may trigger fallback. Sentinel closure must include deterministic repeat,
H0 minimum-spanning-tree checks, subset/full checks, and cross-engine
equivalence on the admitted scope.

## Dissertation-aligned landscape definition

Landscapes are essential to this project and use the owner-approved corrected
definition:

- retain all finite intervals with positive persistence;
- exclude the infinite essential H0 interval;
- retain every consecutive active landscape level;
- calculate H0 and H1 separately as primary outputs;
- integrate squared L2 exactly or with an explicit error-controlled oracle on
  the dimension-specific support;
- use no universal fixed grid and no universal landscape-level cap; and
- stream or chunk computation without storing enormous dense landscape
  matrices.

Zero padding is used only when comparing above one diagram's active depth.
Any combined H0/H1 summary is secondary and may be formed only after separate
component distances and contribution checks exist.

The accepted Rust landscape kernel source remains hash-bound in the
repository, but the current WSL environment has neither its accepted binary
nor the locked Rust toolchain. No landscape execution is authorized until the
kernel is rebuilt from the locked source, its binary is hash-rebound, and it
passes canonical R-oracle and deterministic-repeat checks. The R definition
remains authoritative.
