# MV5-AI selection-resistant nested-256 continuation gate specification v1

Date frozen: 2026-08-11

Accepted base: `fbda3eb`

New calculation/outcome state: zero

## Purpose

MV5-AI decides whether the prespecified robustness sequence should continue
after the complete PC20, cosine-chord, and nested-192 analyses. It may authorize
only the canonical remaining configuration. It cannot select a setting because
a representation, homology dimension, tissue, endpoint, seed, estimate,
interval, p-value, method rank, winner, or subgroup appears favorable.

The immutable MV5-V order is:

1. 384 cells / 20 coordinates / Euclidean — complete;
2. 384 cells / 30 coordinates / cosine chord — complete;
3. nested 192 cells / 30 coordinates / Euclidean — complete;
4. nested 256 cells / 30 coordinates / Euclidean — next eligible.

## Complete prior evidence

All three accepted analyses are bound without slicing. Each contains 150
prediction groups, 282,800 ranking rows, 150 outcome groups, 3,600 query-method
rows, 7,200 long endpoint rows, 24 macro estimands, 24 intervals, and four
primary tests. Their complete public result and reproducibility evidence is
hash-bound even though no numerical result is an input to the decision helper.

PC20 tests coordinate truncation, cosine chord tests radial-scale geometry, and
nested 192 tests a larger reduction in cell-realization depth. None answers the
prespecified intermediate nested-256 question. The gate does not use signs,
magnitudes, intervals, p-values, ranks, winners, tissues, dimensions,
representations, endpoints, seeds, or favorable subgroups.

## Distinct one-factor question

Nested 256 changes only cell-realization depth from 384 to 256. Coordinate count
remains 30, point metric remains Euclidean, fold-fitted representation and
coordinate source remain unchanged, and the directed held-out-query/training-
reference pair axis remains fixed. SCT and inductive-integrated views remain
separate.

Every view must reuse the frozen SHA-256 deterministic cell order. Its first
192 cells are exactly the accepted nested-192 view and its first 256 cells are
the nested-256 view, so the former is a strict subset of the latter and both
are subsets of the same 384-cell realization. No redraw or outcome-dependent
ordering is permitted.

## Mandatory decision criteria

Authorization requires all nine criteria:

- nested 256 is canonical position four after positions one through three;
- all three complete prior panels are bound without result slicing;
- nested 256 is a prespecified, scientifically distinct intermediate depth;
- only the cell count changes from 384 to 256;
- the 192/256/384 sets share the exact frozen cell order in every view;
- six real nested-256 admissions plus the complete nested-192 execution support
  conservative bounded resource projections;
- the decision interface consumes no subgroup or result statistic;
- a later outcome contract must retain the complete 24-estimand family; and
- this gate stops before calculation, ranking, labels, outcomes, or clustering.

Failure of any criterion yields no authorization. There is no substitute
configuration, outcome-informed repair, or fallback analysis.

## Authorized label-closed scope

Passing the gate authorizes exactly 150 later nested-256 calculation groups:
75 SCT and 75 inductive-integrated groups over 15 folds and five seeds. The
exact scope is 13,500 views, 70,700 biological pairs, 141,400 separate H0/H1
landscape rows in 720 subchunks, 70,700 matched-energy rows, and 282,800
four-method rows.

H0 and H1 remain separate exact, all-active-consecutive-level persistence-
landscape distances. The raw H0/H1 composite remains descriptive. Energy is
recomputed on the same nested-256 coordinates. No universal landscape-level
cap or uniform grid is introduced.

The queue authorizes only a later label-closed calculation. It does not
authorize rankings, tissue access, outcome evaluation, clustering,
within-training pairs, any other configuration, or a manuscript claim.

## Resources and execution guards

The gate binds six real nested-256 admissions and all 150 successful
nested-192 production groups. The complete nested-192 run used 4,439.486 worker
seconds (1.233 hours), at most 53.303 seconds per group, 454,893,568 bytes peak
process-tree RSS, and 1,254,700,479 bytes final private storage. A deliberately
conservative quadratic cell-count factor, `(256 / 192)^2 = 1.7778`, projects
about 2.192 worker-hours, 94.76 seconds per group, 808.7 MB RSS, and 2.23 GB
private storage for nested 256. These are feasibility bounds, not promises.

The frozen envelope is one worker, 600 seconds and 4 GiB process-tree RSS per
group, six aggregate worker-hours, and 4 GiB private storage. A later engine
must bind exact source, runtime, queue, implementation, and subchunk identities.
Every group publishes atomically; source/axis/nesting/shape/PH/MST/landscape/
energy/method-row failure, cap breach, early result access, or other-
configuration/clustering access aborts without automatic repair.

Independent validation must reconstruct source hashes, queue axes, strict
nesting policy, views, H0 MSTs, exact landscapes, energy values, and all
282,800 method rows without production scientific helpers. Prospective
minimum/maximum groups, a clean exact repeat, and immutable resume validation
including timestamps are required during the later execution sprint.

## Interpretation and stop boundary

Passing MV5-AI means only that nested 256 is a distinct, selection-resistant,
feasible next sensitivity calculation. It predicts no biological result and
does not authorize robustness, superiority, equivalence, invariance, or default
claims.

This gate executes no nested-256 calculation. It excludes ranking, labels,
outcomes, clustering, within-training pairs, gene topology, cell/gene fusion,
new data, Rust optimization, defaults, manuscript claims, private/PDF/reviewer
tracking, pushing, and `example_run.r`.
