# MV7-A robustness/confounding evidence-map prefreeze v1

Date: 2026-08-15

## Purpose

MV7-A reconciles the completed MV5 cell-view robustness panels, clustering and
representation comparisons, and the completed MV6 cell/gene/fusion evidence.
It does not recompute topology or select a favorable method. Its purpose is to
identify which MV-07 questions are already answered, which are structurally
unavailable, and which can be answered next using already locked outcomes.

## Immutable scientific boundary

The landscape definition remains the dissertation-aligned corrected contract:
finite positive-persistence intervals; the essential H0 interval excluded;
every consecutive active landscape level; separate H0 and H1; exact or
error-controlled squared-L2 integration on dimension-specific support; no
universal fixed grid; and no universal level cap. The H0/H1 Euclidean
composite is descriptive only.

Cell and gene topology remain separate views. The negative equal-weight fusion
result is retained. MV7-A cannot select the descriptively highest fusion
weight, introduce learned or tissue-specific fusion, change a default, or
promote a manuscript claim.

## Selection firewall

The continuation decision consumes only named evidence coverage, artifact
availability, identifiability, computational reuse, and prerequisite order.
It receives no estimates, intervals, p-values, method ranks, tissue ranks, or
winner labels. All completed results remain available for honest synthesis but
cannot determine which configuration is run next.

## Coverage rules

Each robustness/confounding axis receives one of: `complete`, `partial`,
`gap`, `unavailable`, `not_applicable`, or `deferred`. A partially covered cell
axis is not silently treated as gene-view evidence. Missing library-size or
cell-type-composition fields are recorded as unavailable; they are not replaced
with invented proxies. Complete Vietoris-Rips is the primary filtration, so a
sparse threshold is a future computational method rather than an omitted
tuning parameter in the current contract.

## Next-stage rule

Only diagnostics that reuse accepted sample-level outcomes and authoritative
metadata without new PH may advance first: leave-one-study/tissue influence,
retained-cell-count association, and sequencing-approach stratification with
explicit non-identifiability limits. Gene-panel-size, gene-metric, integrated
gene-view, and external-data work remain closed until those diagnostics expose
a named claim-critical gap.

MV7-A itself performs no label-bearing statistical calculation. A separate,
committed MV7-B contract must freeze endpoints, transformations, exclusions,
resampling, multiplicity, missingness, and claim boundaries before execution.

## Acceptance

- every source exists and is SHA-256 frozen;
- all coverage registries have fixed cardinality and unique axes;
- the corrected landscape contract is unchanged;
- the decision interface contains no numerical result columns;
- the only authorized continuation is MV7-B prefreeze;
- new PH, new data, method selection, advanced fusion, default changes, and
  claim promotion remain false;
- independent validation and a clean byte repeat pass.
