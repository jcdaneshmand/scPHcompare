# Phase 6 Subplan — Biological and Practical Validation

## Objective

Demonstrate what the measured topological signal means and which real research decision scPHcompare improves.

## Task ledger

| ID | Task | Required evidence/output | Acceptance test | Status |
|---|---|---|---|---|
| P6-01 | Choose biological case from existing data | Candidate comparison with annotations, prior knowledge, confounders, and access | Existing-data case has a falsifiable question and feasible validation; otherwise invoke P4-06 explicitly | `not_started` |
| P6-02 | Define interpretation hypotheses | Directional associations and alternative explanations for topology | Hypotheses precede outcome inspection and avoid loop/void metaphors as proof | `not_started` |
| P6-03 | Link topology to annotations | Controlled associations, perturbations, sensitivity, effect sizes | Association persists under named confounder and stability checks or is rejected | `not_started` |
| P6-04 | Test integration-selection utility | Decision rule compared with established metrics on held-out data | Utility is measured by a prespecified endpoint, not anecdotal plots | `not_started` |
| P6-05 | Build diagnostic report | Residual study signal, biological loss, local/global distortion, instability | Each warning has definition, evidence, uncertainty, and recommended interpretation | `not_started` |
| P6-06 | Validate diagnostic | Frozen report applied to held-out/external data | Performance and failure cases are documented without retuning | `not_started` |
| P6-07 | Decide optimization claim | Evidence memo on topology-aware parameter selection | Claim is supported, narrowed to hypothesis, or removed | `not_started` |
| P6-08 | Write interpretation guide | User-facing meaning, limitations, anti-patterns, example decision | A domain user can explain what action the output supports | `not_started` |
| P6-09 | Evaluate G6 | Biological/practical utility packet | Author/domain review approves decision relevance and limits | `not_started` |

## Gate G6 checklist

- [ ] Biological hypotheses and alternatives are explicit.
- [ ] Interpretation is controlled and stable, not geometric metaphor alone.
- [ ] Practical decision and comparator metrics are defined.
- [ ] Held-out validation was performed.
- [ ] User-facing limitations and failure modes are clear.
