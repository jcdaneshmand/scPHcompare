# MV8-J provisional claim-to-evidence map

Date: 2026-08-19  
Status: technical claim map; not a final manuscript or biological-results approval

## Purpose

This map reconciles the existing MV7-J claim inventory with the completed
MV8-I eight-unit common-475 HCA technical validation. It is deliberately
result-bounded: it identifies what the current evidence can support and what
would require exact-500 processing, labels, outcomes, or a new estimand.

## What MV8-I adds

The external run used eight manifest-bound adult bone-marrow HCA H5 inputs,
384 deterministically selected cells per unit, the ordered common-475 panel,
separate 30-PC Euclidean cell and 475-gene correlation-chord gene views,
separate Ripserr H0/H1, and exact critical-breakpoint all-active-level
landscapes. It completed 32 topology profiles and 32 landscape profiles.

| Profile | External range across eight units |
|---|---|
| Cell H0 positive intervals | 383–383 |
| Cell H1 positive intervals | 282–383 |
| Gene H0 positive intervals | 474–474 |
| Gene H1 positive intervals | 409–1,055 |
| Cell H1 active landscape levels | 37–66 |
| Gene H1 active landscape levels | 85–288 |

These are descriptive technical ranges, not biological effect estimates.
The public artifact contains no labels, outcomes, barcodes, expression values,
or private diagrams.

## Decision interpretation

The current evidence is strongest for a methods-focused manuscript with an
external technical-replication section. It supports the corrected landscape
definition, separate cell/gene views, conservative reproducibility claims,
and an explicit panel-sensitivity limitation. It does not support a universal
cell-versus-gene winner, a biological mechanism claim, a clustering claim for
HCA, or broad generalization to unseen tissues or assays.

Exact-500 recovery should therefore be conditional rather than automatic. It
is justified only if a planned manuscript sentence or figure requires an
exact-500 external comparison. Otherwise, common475 can remain a transparent
secondary external harmonization analysis while the manuscript is drafted.
