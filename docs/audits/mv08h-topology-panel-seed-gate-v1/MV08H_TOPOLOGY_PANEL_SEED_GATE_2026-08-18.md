# MV8-H topology panel-seed gate (2026-08-18)

This label-closed gate tests the already frozen 500-gene panel across the five prespecified 384-cell seeds. It does not run PH or landscapes and does not substitute or zero-pad missing genes.

A seed is eligible only when all 500 panel features remain in the SCT output. The public evidence reports counts and hashes only; cell and gene identifiers remain private.
