# MV5-AW corrected-tree partition-policy prefreeze

Date: 2026-08-12

## Outcome

MV5-AW stops safely without authorizing partitions. All eight corrected tree
bundles contain three samples, so the candidate grid is the singleton `k = 2`.
There are no matched resampled matrices from which to estimate stability.

This is not a failure of the corrected landscape definition or tree APIs. It
is a scope limitation of the deliberately bounded realistic smoke. The valid
next scientific choice is whether to calculate larger complete corrected
matrices and a label-closed resampling panel. That is materially more expensive
and broadens calculation scope, so it requires project-owner direction rather
than automatic execution.

Until then, H0/H1 trees are descriptive only. Partitions, evaluation,
visualization, fusion, defaults, legacy changes, new data, claims, and
optimization remain closed.
